FirmaPDF

Firma PDF desde tu Android · procesamiento local

1. Elige el documento

Selecciona un PDF o ábrelo desde otra aplicación usando «Abrir con FirmaPDF».

2. Revisa y coloca la firma

Elige un documento PDF para previsualizarlo.

Cuando dibujes tu firma, aparecerá sobre el PDF. Arrástrala con el dedo para colocarla donde corresponda. Puedes moverla de nuevo antes de generar el documento.

Con ubicación personalizada, toca la página para elegir el centro de la firma. Revisa que no tape texto importante.

3. Firma con el dedo

Dibuja tu firma dentro del recuadro. El trazo por sí solo no verifica la identidad civil del firmante.

4. Aceptación y generación

Carga un PDF, dibuja la firma e indica la aceptación para continuar.

Elige WhatsApp, correo u otra aplicación compatible.

Privacidad y evidencias

El PDF se procesa en el dispositivo. La aplicación crea una copia firmada y un archivo JSON con la fecha de aceptación y las huellas SHA-256 del documento original y del documento firmado.

El registro JSON es una evidencia complementaria: no es una firma digital certificada ni acredita por sí solo la identidad del firmante. Se necesita internet para cargar las bibliotecas PDF.
